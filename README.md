# عرض موقع منتدى حوار الشباب

عرض تقديمي على شكل موقع: شرائح تُقلب بزرّي «التالي» و«السابق»، أو بأسهم لوحة المفاتيح، أو بالسحب على الهاتف.

- **الهوية:** مأخوذة من الموقع القديم (ydf.ly) بصياغة حديثة. الأزرق والفيروزي من الشعار، والخط Alexandria. والرمز هو الشخص كما في الشعار: رأس وقوس، وأربعة أشخاص حول مركز واحد.
- **الفصول:** الافتتاح، والفصل الأول (الركائز السبع)، والفصل الثاني (تقييم الموقع الحالي)، والفصل الثالث (الموقع الجديد عبر زر في آخر الفصل الثاني)، والفصل الرابع (الجانب التقني والتوصيات التقنية). يُضاف لاحقاً: الفصل الخامس (التوصيات العامة) والشكر.
- **رابط شريحة بعينها:** `#رقم`، مثل `index.html#7`.

الصفحة مستثناة من محركات البحث (`noindex` و`robots.txt`).
